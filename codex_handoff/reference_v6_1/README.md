# yurimartins.dev — Interactive Prototype V6.1

This V6.1 builds directly on the **approved V4 text-revision code**. The image-only V6 design direction was used as reference, not as an executable application (no HTML V6 had been delivered).

## Scope and preservation
- **Preserved:** approved headline and bio, home layout, illustration with five interactive spatial-story stages, their animation logic, identity photo, expertise, My Approach, Labs functionality, links and palette.
- **Refined only:** typography, contrast, responsive readable type sizes, focus/click targets, header visual hierarchy, and the brand icon.
- **Icon source:** `image(20261010-015342).png` (user-approved original). The exported transparent raster is a clean background removal/crop of the original geometry; not a new drawing.
- **Email:** not activated because `hello@yurimartins.dev` has not been confirmed as deliverable. Contact remains LinkedIn.

## Test locally
Open `index.html` or run `python -m http.server 8000` in this folder and browse to `http://localhost:8000`. Open `labs.html` to view the experimental research page. No framework, external fonts or CDN required.

## Out of scope
No deployment, GitHub writes, API integration, live Esri partnership claim or live AI inference. The animated scenario and Labs map are synthetic/illustrative.
